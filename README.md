# 家計簿アプリ

Pythonで作成した、コマンドライン操作のシンプルな家計簿アプリです。

収入・支出の登録、一覧表示、月ごとの集計、登録データの削除ができます。データはCSVファイルに保存されるため、アプリを終了したあとも記録を残せます。

## 機能

- 収入の登録
- 支出の登録
- 登録データの一覧表示
- 月ごとの収入・支出・収支の集計
- 登録データの削除
- CSVファイルへの保存

## 使用技術

- Python
- CSV

外部ライブラリは使用していません。

## ファイル構成

```text
.
├── README.md
├── main.py
└── records.csv
```

## 起動方法

以下のコマンドでアプリを起動します。

```bash
python main.py
```

環境によっては、次のコマンドを使用してください。

```bash
python3 main.py
```

## 使い方

起動すると、以下のメニューが表示されます。

```text
家計簿アプリ
1. 収入を登録
2. 支出を登録
3. 一覧を表示
4. 月ごとの合計を表示
5. 登録データを削除
6. 保存して終了
```

番号を入力して、実行したい操作を選択します。

### 1. 収入を登録

収入を登録します。

入力する内容は以下です。

| 入力項目 | 入力例 |
| --- | --- |
| 日付 | `2026-05-04` |
| カテゴリ | `給料` |
| 金額 | `200000` |
| メモ | `5月分の給与` |

日付は `YYYY-MM-DD` 形式で入力します。存在しない日付や形式が違う日付を入力した場合は、再入力を求められます。

### 2. 支出を登録

支出を登録します。

入力する内容は収入登録と同じです。

| 入力項目 | 入力例 |
| --- | --- |
| 日付 | `2026-05-04` |
| カテゴリ | `食費` |
| 金額 | `1200` |
| メモ | `昼食` |

### 3. 一覧を表示

登録済みの収入・支出を一覧表示します。

```text
1. 2026-05-04 | 支出 | 食費 | 1200円 | 昼食
```

### 4. 月ごとの合計を表示

指定した月の収入合計、支出合計、収支を表示します。

年月は `YYYY-MM` 形式で入力します。

```text
集計したい年月を入力してください 例: 2026-05: 2026-05
```

表示例は以下です。

```text
--- 2026-05 の集計 ---
収入合計: 200,000円
支出合計: 1,200円
収支: 198,800円
```

### 5. 登録データを削除

登録済みデータの一覧が表示されるので、削除したいデータの番号を入力します。

```text
削除したい番号を入力してください: 1
```

### 6. 保存して終了

現在の登録内容を `records.csv` に保存して、アプリを終了します。

保存時は日付順に並び替えられます。

## データ形式

登録データは `records.csv` に保存されます。

```csv
date,type,category,amount,memo
2026-04-15,income,給料,141706,無印良品
```

各項目の意味は以下の通りです。

| 項目 | 内容 |
| --- | --- |
| date | 日付 |
| type | `income` または `expense` |
| category | カテゴリ |
| amount | 金額 |
| memo | メモ |

## 月ごとの集計

月ごとの合計を表示する場合は、`2026-05` のように年月を入力します。

対象月の収入合計、支出合計、収支が表示されます。
